# M2: LLM Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `packages/llm`: the `LLMProvider` interface (types in core), the `gemini` / `fake` / `replay` providers, the five wrappers (spend cap → rate limiter → retry → cache → recorder), provider selection from env, and a live Gemini smoke test behind a flag.

**Architecture:**
- **Interface in core:** `packages/core/src/llm/` holds the `LLMProvider` interface, request/chunk/usage types and `LLMError`. They are pure types, so M3's agent loop depends only on core (spec §3 lists `LLMProvider` as a core interface). `packages/llm` implements them and depends on `@frontdesk/core` (`workspace:*` + tsconfig reference).
- **Wrappers are decorators:** each is a function `(inner: LLMProvider, opts) => LLMProvider` that wraps both `stream` and `generate`. Each Redis-backed piece depends on a small store interface (`RateLimitStore`, `SpendStore`, `CacheStore`) with an in-memory implementation for unit tests and a Redis implementation tested in the `infra` project. Both implementations run one shared contract suite.
- **Composition:** `createLLM(env, deps)` reads `LLM_PROVIDER` / `LLM_MODEL` and builds `spendCap(rateLimit(retry(cache(recorder?(gemini)))))`. Replay is never wrapped.

**Tech Stack:** TypeScript 5, `@google/genai` ^2.30, `ioredis` ^6, Zod 4 (`z.toJSONSchema`), `yaml` 2.x, `node:crypto` (sha256), Vitest.

**Spec:** `docs/superpowers/specs/2026-10-22-frontdesk-design.md` (§3 Architecture, §7 LLM layer, §9 Evals (recordings), §11 Error handling, §13 Testing, §14 M2 row, §15)

## Global Constraints

- `packages/core` stays pure. The new `core/src/llm` files are types, plus `LLMError`, with no imports beyond `zod` types.
- `packages/llm` may use `@google/genai`, `ioredis`, `yaml`, `zod`, and `node:*`.
- `SPEND_CAP_USD_MONTHLY` defaults to `0`. Paid calls over the cap fail closed. A paid provider refuses to start when the cap is `0`.
- Retry fires only on 429/5xx, with at most 2 retries (3 attempts total).
- The cache never serves or stores `purpose: "confirmation"` requests, or responses that contain a write tool call.
- Recordings live under `packages/evals/recordings/` and carry `templateHash = sha256(template text + canonical JSON of tool specs)`.
- Free-tier model limits live in `packages/llm/models.yaml`, not in code.
- Never print or commit `GEMINI_API_KEY`. The live test skips cleanly without the key or the flag, so CI needs no key.
- Each package's tsconfig `references` must match its `workspace:*` deps (`tests/lint/workspace-references.test.ts`).
- `pnpm verify` passes at the end of every task. Conventional commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Two PRs.** Part A (Tasks 1–5: interface + providers) uses branch `m2-llm-layer`. Part B (Tasks 6–11: wrappers + selection) uses branch `m2-llm-wrappers`, cut from Part A's tip. Part B's PR targets `main` once A is merged. Until then it is stacked on `m2-llm-layer`.

## Rulings (decisions the spec leaves open)

1. **Model and limits (verified 2026-10-22).** Google's [pricing page](https://ai.google.dev/gemini-api/docs/pricing) (updated 2026-10-19) lists free tiers for `gemini-3.8-flash`, `gemini-3.6-flash`, `gemini-3.5-flash-lite` and others. The [rate-limits page](https://ai.google.dev/gemini-api/docs/rate-limits) (updated 2026-10-15) no longer publishes free-tier numbers and refers readers to AI Studio. It also says limits are per project and that RPD resets at midnight Pacific. The numbers below therefore come from secondary sources (ScriptByAI, Oct 2026), and `models.yaml` marks them `source: secondary, confirm in AI Studio`:
   - `gemini-3.5-flash-lite`: 10 RPM, 500 RPD; paid $0.30 / $2.50 per 1M in/out.
   - `gemini-3.6-flash`: 5 RPM, 20 RPD; paid $0.75 / $3.75 per 1M (through 2026-12-31).

   **Default `LLM_MODEL=gemini-3.5-flash-lite`.** It is Flash-class, and 20 RPD on 3.6 Flash would not survive a single eval run. 3.6 Flash stays in the catalog as an opt-in.
2. **Paid vs free** is set by `LLM_TIER=free|paid` (default `free`), because one Gemini key can be either. Free calls cost $0 but still record `shadowUsd` (the cost at paid prices) for the "≈$x if paid" dashboard. `createLLM` throws `LLMConfigError` when the tier is `paid` and the cap is `0`.
3. **Projected cost** is `ceil(chars(system + messages + tool JSON) / 4) × inPrice + (maxOutputTokens ?? 1024) × outPrice`. Actual cost is added after the call from `Usage`. Months are UTC `YYYY-MM`.
4. **Rate limiter.** RPM is a token bucket (capacity = rpm, refill rpm/60 s). RPD is a counter keyed by the Pacific calendar date. When either is exhausted, the wrapper throws `LLMError{code:"rate_limited", retryAfterMs}` and does not sleep. Spec §7's "one moment, wait briefly, hand off" is a conversation behavior that M3 owns. Following the spec's wrapper order, a cache hit still spends a rate token. We accept that cost to keep the order. Models with no limits in the catalog (`fake`, `replay`) are not limited.
5. **Retry** uses backoff `250 ms × 2^attempt × jitter[0.5, 1)` and honors an upstream `retryAfterMs`. It stops when the next wait would pass `budgetMs` (default 4000 ms) after the first attempt. A stream is retried only if it failed **before its first chunk was yielded**, because partial output can't be taken back.
6. **Cache key** = `sha256(canonicalJson({ mode, model, system, messages, tools, schema? }))`, which covers prompt and tool results. The TTL is 24 h. A hit replays the stored chunks, or the stored value, with usage `{ inputTokens: 0, outputTokens: 0 }` so spend isn't double-counted.
7. **Request carries its template.** `LLMRequest.template = { id, text }` holds the unrendered prompt template. The recorder hashes `template.text` + tools. On a miss, replay throws `stale_recording` if a recording with the same `template.id` exists but has a different `templateHash`, and `replay_miss` otherwise.
8. **Recording layout:** `packages/evals/recordings/<template.id>/<requestKey>.json`, where `requestKey` is the rule-6 key.
9. **Gemini 3 thought signatures:** the provider copies `thoughtSignature` from a `functionCall` part into `ToolCall.signature` and sends it back when that call is replayed in history. Without it, Gemini 3 rejects multi-turn function calling. Thinking tokens count as output tokens.
10. **Selection:** `LLM_PROVIDER` accepts `gemini | replay` (default `gemini`). `fake` is built directly in tests. Any other value throws `LLMConfigError` listing the allowed values. Recording turns on with `LLM_RECORD=1` (gemini only).
11. **Test placement:** `*.smoke.test.ts` (Redis) and `*.live.test.ts` (Gemini) may live in package `src/`. The `unit` project excludes both. The `infra` project adds `{apps,packages}/*/src/**/*.smoke.test.ts`. A new `live` project runs `*.live.test.ts` through `pnpm test:live`, which sets `LLM_LIVE=1`.

## Review Focus

1. **A stream fails after it has emitted text** (a 503 mid-reply). Retrying would make the caller hear the reply twice, so retry must rethrow instead of restarting. Test in Task 8.
2. **A write tool call appears only in the last chunk of a stream.** The cache has already passed earlier chunks through, so it must decide at the end of the stream and store nothing. Test in Task 9.
3. **Two calls race past the spend cap** (projected cost fits for each, but not for both). Accepted: the check runs per call, the overshoot is at most one call, and the next call fails closed. Test that the call after the overshoot is refused. Task 7.
4. **Gemini returns JSON that doesn't match the Zod schema, or isn't JSON at all.** `generate` throws `LLMError{code:"invalid_output", retryable:false}` with the Zod issue in the message. It must not return `undefined`, and it must not be retried. Test in Task 3.
5. **The RPD day boundary.** At 23:59 Pacific the counter belongs to that day, and at 00:00 Pacific it resets. The boundary is not UTC midnight. Test in Task 6.

  type LLMPurpose = "turn" | "confirmation" | "grounding" | "summary";

### Task 3: Gemini provider

**Files:** Create `packages/llm/src/providers/gemini.ts`. Test: `packages/llm/src/providers/gemini.test.ts`.

**Interfaces:**
- Consumes: the core types and `LLMError`.
- Produces: `type GeminiModels = Pick<GoogleGenAI["models"], "generateContent" | "generateContentStream">` and `class GeminiProvider implements LLMProvider { constructor(opts: { model: string; apiKey?: string; client?: GeminiModels }) }`. Exactly one of `apiKey` or `client` is used. Tests inject `client`.
- Mapping (to the SDK `contents` / `config`):
  - `system` → `config.systemInstruction`.
  - `user` → `{ role: "user", parts: [{ text }] }`.
  - `assistant` → `{ role: "model", parts: [{ text }?, ...toolCalls.map(c => ({ functionCall: { id, name, args }, thoughtSignature: c.signature }))] }`.
  - `tool` → `{ role: "user", parts: [{ functionResponse: { id: callId, name, response: { result } } }] }`.
  - `tools` → `config.tools = [{ functionDeclarations: tools.map(t => ({ name, description, parametersJsonSchema: t.parameters })) }]`. The `effect` field is not sent.
  - `temperature` and `maxOutputTokens` pass straight through.
- Stream output: text parts become `text` chunks. Each `functionCall` part becomes a `tool_call` (id = `functionCall.id ?? \`call_${n}\``, signature = `part.thoughtSignature`). After the last response, one `usage` chunk is emitted from the final `usageMetadata`: `inputTokens = promptTokenCount`, `outputTokens = candidatesTokenCount + (thoughtsTokenCount ?? 0)`.
- `generate`: sets `config.responseMimeType = "application/json"` and `responseJsonSchema = z.toJSONSchema(schema)`, then runs `JSON.parse` and `schema.safeParse`. Any failure throws `invalid_output`.
- Errors: SDK `ApiError` (it has `.status`) → `LLMError(status === 429 ? "rate_limited" : "upstream", …, { status, cause })`. A network `TypeError` → `upstream` with status 503, so it is retryable. The message never contains the API key.
